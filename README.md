# Эмуляторы Hercules для запуска zOS

Развёрнуто 8 экземпляров эмулятора hercules `zOS-3270..zOS-3277` (каталоги в домашней директории)

Все экземпляры запущены при помощи tmux.

Общие файлы: архив образа zOS (`_0_zOS.113.s.2013.zip`) и этот файл README хранятся в домашней директории.

Настроена возможность подключения всего 5 человек для каждого из 8 портов `3270..3277`! Настройка количества терминалов доступна в конфигурационных файлах `zOS-327${i}/hercules.cnf`.

## Доступ к zOS

### Предварительные требования к пользовательским машинам

1. Находиться во внутренней сети МГТУ им. Баумана
2. Установить эмулятор терминала 3270:
    * Linux: установить `apt install c3270`, запуск `c3270 <host>:3270`
    * Windows: установить программу `tn3270`, настроить подключение при запуске основной иконки и согласиться на конфигурирование новых иконок
    * MacOS: установить `brew install x3270`, запуск `c3270 <host>:3270`

### Подключение к серверам

Следует подключиться к серверу `hostname` (следует взять из методических указаний) по порту `3270..3277` (выбрать один порт):

```bash
c3270 <hostname>:<port>
```

#### Подключение к пользователям для проведения ЛР

В окне приветствие zOS следует ввести:

```bash
logon <Логин>
```

Логины: ADCDA..ADCDZ (то есть ADCDA, ADCDB, ADCDC и так далее)
Пароль: TEST (при первом подключении попросит сменить)

Для каждого порта по-умолчанию существует по 26 заранее подготовленных пользователей

#### Подключение к суперпользователю

В окне приветствие zOS следует ввести:

```bash
logon ibmuser
```

Пароль: `ibmuser`

### Повторное подключение

Если отключить все терминалы от сессии, то ничего не пропадёт. Первый подключенный терминал станет управляющим терминалом IPL: на нём отобразится приветствие эмулятора hercules. Все последующие терминалы будут подключены как терминалы TSO: на них отобразится приветствие zOS.

Если не выйти из сессии в предыдущем терминале, то после повторного подключения и ввода пароля будет выведено сообщение об ошибке. Достаточно ввести `logoff` чтобы выйти, затем `logon` для повторного входа. Система знает что Вы знаете свой пароль.

## Развёртывание

### Установка зависимостей ansible

```bash
ansible-galaxy install -r requirements.yml
```

### Доступ по ssh

После подготовки возможно получить доступ к машинам при помощи команды:

```bash
ansible -i inventory.yaml all --module-name include_role --args name=bmstu.vats.ssh_connection
```

### Копирование "чистого" дистрибутива zOS

На машине следует выполнить

```bash
# Удаление уже развёрнутых zOS
rm -rf zOS-327{0..7}

# Создание директорий установки
mkdir zOS-327{0..7}

# Развёртывание дистрибутивов
for i in {0..7}; do unzip -d zOS-327${i} _0_zOS.113.s.2013.zip; done
```

### Копирование конфигурации

```bash
ansible-playbook -v -i inventory.yaml playbooks/_01_copy_config.yaml
```

### Запуск серверов hercules

Для каждого из серверов `i in {0..7}` следует:

1. Зайти в рабочую директорию `cd zOS-327${i}`
2. Создать сессию tmux `tmux new-session -t ${PWD##*/}`
3. Запустить `hercules`
4. Создать новое окно `CTRL+b` и `c`
5. Запустить `c3270 <hostname>:${PWD##*-}`
6. Вернуться в предыдущее окно `CTRL+b` и `n`
7. Запустить работу hercules: `ESC`, `l` (переход в режим инициализации IPL) и `a` (выбрать первый загруженный образ диска для загрузки)
8. Подключить внешний терминал `c3270 <hostname>:327${i}`, через некоторое время в нём отобразится приветствие
9. Ввести `logon ibmuser`, пароль `ibmuser`
10. Добро пожаловать в сессию TSO!
